# 100 Years Ago

A TRMNL plugin

## Description

A TRMNL plugin that pulls from a JSON database to find information from exactly 100 years ago. I dug through NOAA records, the New York Times archive, and old stock market data to write up the JSON file, and then wrote up an HTML file to pull the data. I figured it would be interesting to check it every day and see how different things were in 1926. Some notes:
* Since I REALLY didn't want to API pull 10 different databases, I just hardcoded the info. Unfortunately, there is a limit around Nov 25. If you use it past then, it will probably break.
* NYT info is from TimesMachine. Weather info is from a NOAA station in Washington, D.C.
* Originally for TRMNL Jam, but I never did enough hours to finish, and jam owner allowed me to transfer it to his other project, Crossroads

## Dependencies + Instal

* Just a browser!
* Open the demo link at https://richardkiselev.github.io/100yearsago/
